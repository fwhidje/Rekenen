# Flemish curriculum references

External reference material for the curriculum design: what Flemish goal documents and
teacher-training material say about numbers, splitsen and optellen / aftrekken up to 10.
Rekenen follows the **Flemish** progression; Dutch material (TAL, SLO, Dutch methods) is
organised differently and is deliberately not collected here.

These files are **extracts**, not copies: only the passages that concern kleuters and the
first year of lager onderwijs (numbers up to 10, at most 20), transcribed from the text
layer of the original PDFs. Tables, colours and age-grid columns are not preserved. For
anything load-bearing, open the original.

| File | Source | What it is |
|---|---|---|
| `minimumdoelen-wiskunde.md` | *Minimumdoelen wiskunde basisonderwijs*, reading version by Els Van Emelen (UCLL) and Filip Moons (Universiteit Utrecht), published by Leerpunt | The Flemish minimum goals, milestones end of kleuterschool / 4th year / 6th year |
| `go-doelenset-bewerkingen.md` | *Doelenset BaO wiskunde – bewerkingen*, GO! onderwijs van de Vlaamse Gemeenschap | GO!'s goal set built on the minimumdoelen: goals WI.265–WI.281 on getalfamilies and optellen / aftrekken to 10, with examples |
| `ucll-leerlijnen.md` | UCLL lerarenopleiding basisonderwijs Limburg (Van Emelen, Dexters, Sijmkens): *Leerlijn bewerkingen: hoofdrekenen*, *Leerlijn getallenkennis*, *Overzicht bewerkingen*, *Het vakdidactisch kader – toegelicht voor getallenkennis* | Year-by-year learning lines and the didactic framework (CSA, splitsen, automatiseren) |

Retrieved 15 November 2026. Source URLs are in each file.

## How these are used

- They are **evidence for design decisions**, cited from `rekenen_v2_skill_exercise_map.md`
  (curriculum design rationale) and from the `didactics` fields in `src/curriculum/skills.ts`.
- They carry no status and no decisions of this project. Do not edit the quoted text. Add a
  new file (and a row above) when a new source is consulted.
- Not yet consulted, and worth adding: the ZILL leerplan (Katholiek Onderwijs Vlaanderen),
  the OVSG leerplan, and the teacher's guide of the method used at the child's school.

## Rights

The texts belong to their authors and publishers. The extracts are short quotations kept
for reference with their source. The UCLL documents ask for a proper source reference for
internal use and to be contacted before use on a larger scale — which is why the full
documents are not stored in this repository.
